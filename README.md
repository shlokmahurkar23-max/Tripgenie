# TripGenie — professional multi-page travel-planning prototype

A responsive, multi-page travel planning website built with plain HTML, CSS and JavaScript. No framework or build step is required.

## Pages (12)
1. `index.html` — home and quick trip search
2. `destinations.html` — destination cards and travel-style filters
3. `packages.html` — curated sample packages
4. `family-trips.html` — family-first travel features
5. `budget-planner.html` — editable group budget calculator
6. `itinerary-builder.html` — sample day-by-day itinerary and custom activities
7. `memory-spots.html` — photo and memory inspiration with saved ideas
8. `trip-customizer.html` — revise a trip while travelling
9. `offers.html` — family and group-value offers
10. `about.html` — product story and transparency notes
11. `journal.html` — travel-planning articles
12. `contact.html` — local enquiry preview form

## Run locally
- Extract the ZIP.
- Open `index.html` in a modern browser. If your browser restricts local files, use VS Code Live Server or another simple local static server.
- Internet access is required for remote Unsplash images and Google Fonts.

## Functional demo features
- Responsive mobile navigation
- Destination and travel-style search/filtering
- Save trip cards and memory ideas using browser `localStorage`
- Group total and per-person budget calculator
- Sample day-by-day itinerary generator, custom activity additions and stop removal
- Mid-trip modification suggestions and saved revised-plan text
- Contact/enquiry preview and copy action

## Important limitations
- This is a frontend prototype. It does not book travel, process payments, send enquiry forms to a server, or connect to a real AI model.
- Trip prices and recommendations are illustrative sample data, not live prices or verified availability.
- Maps, live weather, traffic, opening hours, booking systems, authentication and real AI itinerary generation require appropriate APIs and backend work.
- The photo URLs load images from Unsplash's image CDN. Confirm each image's licence/terms and replace any image you use commercially with properly licensed assets. Internet access is needed to display photos.
- Browser-saved plans remain on the current browser/device only. There is no cloud account or cross-device sync.

## Design notes
Editorial travel aesthetic: deep forest green, warm ivory, restrained amber accents, photographic cards, rounded panels, clear cost labels and consistent page navigation. Built to be distinct from a simple single-page demo.
